# عکس محصولات: جایگزینی، یکدست‌سازی و نمای چرخشی

## افزودن یا جایگزینی عکس از پنل

پنل ← محصولات ← ویرایش محصول ← «تصاویر»:

- قالب JPEG، PNG، WebP یا AVIF تا ۸ مگابایت. سرور نوع فایل را از محتوای آن تشخیص می‌دهد، به WebP تبدیل می‌کند و متادیتا (EXIF، GPS) را حذف می‌کند.
- **متن جایگزین (alt)** الزامی است: لباس را توصیف کنید (رنگ، پارچه، فرم)، نه «عکس ۱».
- **رنگ مرتبط**: با انتخاب رنگ در صفحهٔ محصول، تصاویر همان رنگ اول نمایش داده می‌شوند.
- **نوع**: «گالری» یا «فریم نمای چرخشی». ترتیب با پیکان‌ها تغییر می‌کند؛ اولین تصویر گالری عکس اصلی کارت محصول است.

## یکدست‌سازی پس‌زمینه (روش استفاده‌شده برای عکس‌های فعلی)

عکس‌های فعلی محصولات (`prisma/seed/photos/*.webp`) با دو اسکریپت [`docs/photo-tools`](photo-tools) آماده شده‌اند.
این ابزارها عمداً جزو وابستگی‌های پروژه نیستند؛ آن‌ها را در یک پوشهٔ جداگانه بیرون از پروژه اجرا کنید:

```bash
mkdir ../roshak-photo-tools && cd ../roshak-photo-tools
cp <مسیر-پروژه>/docs/photo-tools/*.mjs .
npm init -y && npm install @imgly/background-removal-node sharp
node remove-background.mjs "<پوشهٔ عکس‌های اصلی>" cutouts     # حذف پس‌زمینه، مدل محلی medium (بدون ارسال عکس به سرویس بیرونی)
node compose-studio.mjs cutouts composed                       # استودیوی یکسان
```

1. **حذف پس‌زمینه** با [`@imgly/background-removal-node`](https://www.npmjs.com/package/@imgly/background-removal-node) — مدل یک‌بار دانلود می‌شود و پردازش روی همین رایانه انجام می‌شود.
2. **استودیوی یکسان**: قاب ۱۲۰۰×۱۶۰۰ (نسبت ۳:۴)، دیوار عاجی با طاق ظریف طلایی، کف روشن، سایهٔ نرم زیر لباس؛
   لباس حداکثر ۹۰٪ ارتفاع قاب، در مرکز و با پایینِ روی یک خط کف ثابت.
3. **خروجی** WebP با کیفیت ۸۸. فایل‌ها را در پنل بارگذاری کنید یا برای seed در `prisma/seed/photos` با الگوی نام `<محصول>-<رنگ>-<زاویه>.webp` بگذارید.

نکته‌ها: لبه‌های تور و پارچهٔ نیمه‌شفاف را پس از حذف پس‌زمینه با دقت بررسی کنید؛ برای عکس‌های جدید از عکاسی با پس‌زمینهٔ ساده و نور یکنواخت شروع کنید
تا نیاز به اصلاح کمتر باشد. عکس‌ها باید متعلق به خود فروشگاه یا دارای مجوز استفاده باشند.

## نمای چرخشی و ۳۶۰ درجه

- با **۲ فریم یا بیشتر** از نوع «فریم نمای چرخشی»، زبانهٔ «نمای چرخشی» در صفحهٔ محصول فعال می‌شود (کشیدن، کلیدهای جهت، دکمه‌های زاویه).
- با **۸ فریم یا بیشتر** برچسب آن «نمای ۳۶۰ درجه» می‌شود. برای چرخش روان، ۲۴ تا ۳۶ فریم با فاصلهٔ زاویهٔ یکسان
  (میز گردان، دوربین ثابت، نور ثابت) بگیرید و به ترتیب زاویه بارگذاری کنید.
- وضعیت فعلی: محصولاتی که چند زاویهٔ واقعی دارند (مثلاً «شب‌تاب»: جلو و پهلو) فقط **۲ زاویهٔ واقعی** دارند؛ این یک نمای چرخشی محدود است،
  نه ۳۶۰ درجهٔ کامل. هیچ فریم ساختگی یا تولیدشده اضافه نشده است.
- نمای سه‌بعدی فقط وقتی نمایش داده می‌شود که برای همان لباس مدل GLB واقعی در فیلد «نشانی مدل سه‌بعدی» ثبت شده باشد.

## عکس‌های seed

`npm run db:seed` عکس‌های `prisma/seed/photos` را در ذخیره‌سازی کپی می‌کند و برای هر رنگ عکس جلو، یک برش جزئیات و عکس پهلو/پشت (در صورت وجود) می‌سازد.
کمبود فعلی: رنگ مشکی محصول «گلبرگ» فقط عکس پشت دارد.
