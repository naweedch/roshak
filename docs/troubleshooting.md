# رفع اشکال

### «پیکربندی متغیرهای محیطی نامعتبر است»
پیام خطا نام متغیر را می‌گوید. رایج‌ترین: `TOKEN_HASH_SECRET` خالی یا کوتاه‌تر از ۳۲ کاراکتر، یا `APP_URL` بدون `http(s)://`. — [environment.md](environment.md)

### پورت 3000 اشغال است
روی برخی سیستم‌ها (مثلاً سرویس VPN) پورت 3000 در اختیار برنامهٔ دیگری است. با پورت دیگر اجرا کنید: `npm run dev -- -p 3100` و `APP_URL` را همان بگذارید.

### `npm run db:local` اجرا نمی‌شود یا پورت 5433 اشغال است
- نمونهٔ قبلی هنوز در حال اجراست: همان ترمینال را ببندید یا پورت را با `LOCAL_PG_PORT` تغییر دهید (و `DATABASE_URL` را هم).
- داده‌ها در `~/.roshnak/postgres` هستند؛ برای شروع از صفر (همهٔ داده‌ها پاک می‌شوند) این پوشه را پس از توقف PostgreSQL حذف کنید.

### Turbopack پشت سر هم بازسازی می‌کند
پوشهٔ دادهٔ PostgreSQL یا فایل‌های پرتغییر دیگر داخل پروژه هستند. `LOCAL_PG_DATA_DIR` را بیرون از پروژه نگه دارید (پیش‌فرض همین است).

### `npm run test:integration`: «TEST_DATABASE_URL تنظیم نشده» یا «نام پایگاه داده باید شامل test باشد»
این محافظت عمدی است تا تست‌ها پایگاه توسعه را پاک نکنند. `TEST_DATABASE_URL` را به `.../roshnak_test` بدهید.

### `npm run test:e2e`: «Executable doesn't exist»
مرورگر داخلی Playwright نصب نیست. یا Chrome/Edge سیستم را استفاده کنید (`E2E_BROWSER_CHANNEL=chrome` یا `msedge`، پیش‌فرض محلی)
یا `npx playwright install chromium`. دانلود مرورگر Playwright از برخی شبکه‌ها ممکن نیست.

### بعد از تغییر محصول در پنل، فروشگاه تغییر نمی‌کند
پنل پس از هر ذخیره کش مربوط را باطل می‌کند. اگر داده را مستقیم در پایگاه داده تغییر داده‌اید، سرور را دوباره راه‌اندازی کنید.

### ایمیل‌ها نمی‌رسند
- `EMAIL_PROVIDER=log`: ایمیل‌ها فقط در `.data/mail` ذخیره می‌شوند.
- با SMTP: جدول `EmailOutbox` ستون `lastError` را دارد؛ کار دوره‌ای (`npm run jobs:run`) صف را دوباره ارسال می‌کند.

### سفارش «در انتظار پرداخت» می‌ماند و موجودی آزاد نمی‌شود
کارهای دوره‌ای زمان‌بندی نشده‌اند. — [deployment.md](deployment.md#کارهای-دوره‌ای)

### «درخواست از مبدأ غیرمجاز رد شد»
درخواست تغییر داده از دامنه‌ای غیر از `APP_URL` آمده است. `APP_URL` را دقیق تنظیم کنید یا دامنهٔ اضافی را در `ALLOWED_ORIGINS` بگذارید.

### ورود به پنل پس از چند ساعت قطع می‌شود
عمدی است: نشست کارکنان پس از ۴ ساعت بی‌فعالیتی و حداکثر ۱۲ ساعت منقضی می‌شود (مشتریان ۳۰ روز / حداکثر ۹۰ روز).

### تصاویر S3 نمایش داده نمی‌شوند
`S3_PUBLIC_URL` هنگام build در CSP و `next/image` ثبت می‌شود؛ پس از تنظیم یا تغییر آن دوباره build کنید.
