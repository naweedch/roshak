# روشاک (ROSHAK)

فروشگاه اینترنتی لباس مجلسی و لباس شب زنانه — فارسی، راست‌به‌چپ، با پنل مدیریت کامل.

> وضعیت دقیق آنچه پیاده‌سازی و آزموده شده و آنچه هنوز باقی است: [docs/status.md](docs/status.md)

## امکانات

**فروشگاه**
- کاتالوگ با فیلتر (دسته، مجموعه، رنگ، سایز، قیمت، قد)، مرتب‌سازی و جست‌وجوی فارسی (یکسان‌سازی ی/ک و ارقام)
- صفحهٔ محصول با گالری، بزرگ‌نمایی، نمای چرخشی از عکس‌های واقعی چندزاویه، راهنمای سایز و نظرات تأییدشده
- سبد خرید سمت سرور (مهمان و کاربر)، کد تخفیف، تسویه با محاسبهٔ کامل قیمت در سرور
- پرداخت: درگاه آزمایشی برچسب‌دار برای توسعه + آداپتور زرین‌پال (تأیید پرداخت فقط سمت سرور)
- حساب کاربری: ثبت‌نام، تأیید ایمیل، بازیابی رمز، نشانی‌ها، سفارش‌ها، علاقه‌مندی‌ها؛ پیگیری سفارش مهمان
- مجله، صفحات ثابت، پرسش‌های پرتکرار، خبرنامه با تأیید دومرحله‌ای، فرم تماس
- سئو: متادیتای قابل ویرایش، JSON-LD (محصول، سازمان، مقاله، مسیر)، نقشهٔ سایت و robots

**پنل مدیریت** (`/admin`)
- پیشخوان با شاخص‌های واقعی، سفارش‌ها (تغییر وضعیت طبق ماشین حالت، ارسال، بازپرداخت، یادداشت، خروجی CSV)
- محصولات، تنوع‌ها، تصاویر (WebP، حذف متادیتا)، انبار و تاریخچهٔ حرکات
- دسته‌ها و مجموعه‌ها، تخفیف‌ها، مشتریان، نظرات، محتوا، مجله، تنظیمات، روش‌های ارسال، گزارش ممیزی
- نقش‌ها: مدیر ارشد، مدیر، مدیر محصول، مدیر سفارش، مدیر محتوا — مجوزها در سرور بررسی می‌شوند

## فناوری‌ها

Next.js 16 (App Router، Cache Components) · React 19 · TypeScript · Tailwind CSS 4 · PostgreSQL + Prisma 7 ·
Argon2id · Zod 4 · three.js / React Three Fiber (بارگذاری تنبل) · Motion · Vitest · Playwright + axe

## شروع سریع (توسعهٔ محلی)

پیش‌نیاز: Node.js 24 و npm. Docker لازم نیست (PostgreSQL محلی با بستهٔ embedded-postgres اجرا می‌شود).

```bash
npm install
cp .env.example .env          # سپس TOKEN_HASH_SECRET، LOCAL_PG_PASSWORD و SEED_ADMIN_PASSWORD را پر کنید
npm run db:local              # در یک ترمینال جداگانه؛ PostgreSQL روی پورت 5433
npm run db:deploy             # اعمال مهاجرت‌ها
npm run db:seed               # دادهٔ نمونه + حساب مدیر توسعه از SEED_ADMIN_*
npm run dev -- -p 3100        # http://localhost:3100  |  پنل: http://localhost:3100/admin
```

جزئیات: [docs/setup.md](docs/setup.md)

## دستورها

| دستور | کار |
|---|---|
| `npm run dev` / `build` / `start` | توسعه، ساخت (خروجی standalone)، اجرا |
| `npm run typecheck` / `lint` | بررسی نوع‌ها و ESLint |
| `npm run test:unit` | تست‌های واحد (قیمت، تخفیف، موجودی، ماشین حالت، مجوزها، امضای وب‌هوک، اعتبارسنجی) |
| `npm run test:integration` | تست‌های یکپارچه روی پایگاه دادهٔ جداگانهٔ `TEST_DATABASE_URL` |
| `npm run test:e2e` | تست‌های سرتاسری Playwright + بررسی دسترس‌پذیری axe |
| `npm run check` | typecheck + lint + همهٔ تست‌های Vitest |
| `npm run db:local` | PostgreSQL محلی بدون Docker |
| `npm run db:migrate` / `db:deploy` / `db:seed` / `db:studio` | مهاجرت توسعه / اعمال مهاجرت / دادهٔ نمونه / Prisma Studio |
| `npm run admin:create -- --email ...` | ساخت حساب مدیر (بدون رمز پیش‌فرض) |
| `npm run jobs:run [-- --loop]` | کارهای دوره‌ای: لغو سفارش‌های منقضی، صف ایمیل، پاک‌سازی |

## ساختار پوشه‌ها

```
prisma/            طرح پایگاه داده، مهاجرت‌ها و seed (عکس‌های پردازش‌شدهٔ محصولات در prisma/seed/photos)
scripts/           db-local، create-admin، run-jobs
src/app/           صفحات فروشگاه (store)، پنل admin، API نسخهٔ v1 در api/v1
src/components/    رابط کاربری (ui، store، product، admin، home، three)
src/lib/           منطق خالص و مشترک (قیمت، موجودی، مجوزها، اعتبارسنجی، متن فارسی)
src/server/        سرویس‌ها، احراز هویت، پرداخت، ایمیل، ذخیره‌سازی، کش
tests/             unit، integration، e2e
docs/              مستندات
```

## اصول امنیتی

- قیمت، موجودی، تخفیف و مبلغ نهایی همیشه در سرور و در یک تراکنش محاسبه می‌شوند؛ کسر موجودی اتمی است.
- سفارش فقط پس از تأیید سمت سرور از درگاه «پرداخت‌شده» می‌شود؛ رسیدن به آدرس بازگشت کافی نیست.
- نشست‌ها در پایگاه داده با هش HMAC توکن؛ رمزها با Argon2id؛ کوکی HttpOnly؛ بررسی مبدأ برای درخواست‌های تغییر داده.
- هیچ رمز یا کلیدی در کد نیست؛ هیچ رمز پیش‌فرضی برای مدیر وجود ندارد؛ اطلاعات کارت ذخیره نمی‌شود.
